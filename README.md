# AIPUSH

AIPUSH is a free AEO (Answer Engine Optimization) analyzer at [aipush.app](https://aipush.app). Paste a URL and it runs 43 checks (32 scored) that show how well the page can be found and cited by AI assistants such as ChatGPT, Perplexity, Gemini and Claude. The report lists each failed check with a concrete fix. The check catalog, weights and ladder are published at [aipush.app/methodology](https://aipush.app/methodology) (the canonical statement stays in the methodology section of the private repository's `docs/aeo-design-brief.md`); the list of check ids is also at [aipush.app/llms.txt](https://aipush.app/llms.txt). Unlocking the full report takes a confirmed email address. This repository holds the public web frontend; the backend lives in a private repository.
